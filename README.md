# Gestion-Pedidos-Restaurante

Trabajo final - Fundamentos de Programación 1 - UPC

## Descripción
Programa en Python que registra los pedidos de un restaurante pequeño: muestra el menú, registra los productos y cantidades, calcula el total, cobra y calcula el vuelto.

## Cómo ejecutar
1. Abrir el archivo pedidos.py en Python (IDLE, Google Colab o la terminal).
2. Ejecutar el programa y seguir las instrucciones en pantalla.

## Versiones
- Versión 1: menú y datos del cliente.
- Versión 2: registro de productos y total.
- Versión 3: validación, pago y vuelto.
